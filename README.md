# Block Puzzle (с вращением фигур)

Офлайн головоломка для Android в духе классических block-паззлов, но с
уникальной механикой: фигуры можно свободно вращать перед тем, как поставить
их на поле. Встроенный конструктор позволяет создавать собственные уровни —
свой размер поля, свои фигуры, свои вероятности их появления.

## Возможности

- Классическая механика: перетаскивайте фигуры на поле, собирайте полные
  строки и столбцы, чтобы очистить их и заработать очки.
- **Вращение фигур** — фигуру можно повернуть на 90° перед установкой.
- **Конструктор уровней** — свои игровые режимы:
  - размер поля — любой квадрат от 5×5 до 8×8;
  - режим — однотонный или цветной (очки за монохромные линии);
  - алгоритм выбора фигур — случайный (с настраиваемыми весами) или
    «хитрый» (подстраивается под сложность игры, но оставляет шанс выиграть);
  - свои фигуры — рисуются на сетке; фигура и её зеркальное отражение всегда
    считаются одной фигурой.
- Рекорд и незавершённая партия хранятся отдельно для каждого уровня —
  можно держать «на паузе» сколько угодно уровней одновременно.
- Топ-5 уровней по рекорду на главном экране — с них можно сразу начать игру.
- Полностью офлайн: приложению не нужен доступ в интернет.

## Технологии

- Kotlin + Jetpack Compose (Material 3)
- Архитектура MVVM
- Локальное хранилище на Jetpack DataStore (Preferences); список уровней
  сериализуется в JSON через `kotlinx.serialization`
- Юнит-тесты на JUnit4 для игровой логики — домен не зависит от Android SDK

## Структура проекта

```
app/src/main/java/com/blockpuzzle/rotate/
├── domain/   — чистая Kotlin-логика: движок игры, генерация и геометрия
│               фигур, модель уровня — без зависимостей от Android
├── data/     — хранилища на DataStore (уровни и рекорды)
└── ui/       — экраны и компоненты на Jetpack Compose, ViewModel
```

Подробности архитектуры и принятых решений — в [`CLAUDE.md`](CLAUDE.md).

## Сборка и запуск

Нужен установленный Android SDK. Скопируйте `local.properties.example` в
`local.properties` и укажите путь к своему SDK — этот файл не хранится в
репозитории, так как путь у каждого свой.

```bash
# Сборка debug-APK
./gradlew.bat assembleDebug

# Юнит-тесты
./gradlew.bat testDebugUnitTest

# Установка на подключённое по USB устройство
adb install -r app/build/outputs/apk/debug/app-debug.apk
```
